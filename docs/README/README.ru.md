# CloseUp

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Português](README.pt-BR.md) · **Русский**

**Верните элементы управления в Mission Control.** CloseUp накладывает элементы управления окнами на нативный Mission Control в macOS — закрывайте, сворачивайте, разворачивайте, скрывайте или завершайте любое окно, не покидая обзор, — и добавляет полное управление с клавиатуры. Бесплатно, нативно и с открытым исходным кодом.

## Возможности

- **Закрытие из обзора** — наведите указатель на миниатюру окна в Mission Control и нажмите красный ×, чтобы мгновенно закрыть окно, не переключаясь на него.
- **Все действия с окном** — сворачивайте, разворачивайте, скрывайте программу или завершайте её работу. «Закрыть», «Свернуть» и «Развернуть» — это дополнительные кнопки, которые можно включить или отключить в настройках; «Скрыть» и «Завершить» показываются всегда, если окно это поддерживает.
- **Управление с клавиатуры** — выполняйте над окном под указателем нативные действия: ⌘W закрыть, ⌘M свернуть, ⌘F развернуть, ⌘H скрыть, ⌘Q завершить — все они переназначаемы.
- **Пакетные действия** — ⌥⌘W закрыть все, ⌥⌘M свернуть все, ⌥⌘H скрыть все, кроме окна под указателем.
- **Девять языков** — English, 简体中文, 繁體中文, 日本語, Français, Deutsch, Español, Português, Русский, переключаются прямо в программе и применяются на лету.
- **Нативный и ненавязчивый** — пассивный оверлей, который никогда не перехватывает собственную обработку клавиш Mission Control; работает только в строке меню, без значка в Dock.
- **Автоматическое обновление** — подписанные и нотаризованные выпуски через Sparkle, с необязательным бета-каналом.

|---|---|---|---|---|

| Лицензия | Открытый исходный код (GPL-3.0) | Закрытый исходный код | Открытый исходный код (GPL-3.0) | Закрытый исходный код |

Другие инструменты управления окнами для macOS — [AltTab](https://github.com/lwouis/alt-tab-macos), [DockDoor](https://github.com/ejbills/DockDoor), [HyperDock](https://bahoom.com/hyperdock), [Contexts](https://contexts.co/) — предлагают похожие действия с окнами (закрытие, скрытие, переключение), но через собственный переключатель или всплывающий предпросмотр Dock, а не через нативный экран Mission Control. Они решают смежную, но другую задачу, поэтому не включены в таблицу выше.

## Требования

- macOS 14.0 или новее
- Apple Silicon (arm64) или Intel (x86_64) — CloseUp распространяется в виде
  отдельно подписанной сборки для каждой архитектуры; загрузите версию,
  подходящую вашему Mac
- Разрешение «Универсальный доступ» (CloseUp считывает окна и действует с ними через API Универсального доступа; запись экрана при этом не ведётся)

## Установка

Загрузите версию, соответствующую чипу вашего Mac, из раздела
[Releases](https://github.com/oomol-lab/CloseUp/releases) — `CloseUp-*-arm64.dmg`
для Apple Silicon, `CloseUp-*-x86_64.dmg` для Intel — откройте её и перетащите
CloseUp в папку «Программы». Также можно установить через Homebrew (архитектура
определяется автоматически):

```bash
brew install --cask oomol-lab/tap/closeup
```

При первом запуске предоставьте доступ к Универсальному доступу в «Системных настройках» → «Конфиденциальность и безопасность» → «Универсальный доступ» — CloseUp откроет нужную панель за вас.

## Использование

Откройте Mission Control обычным способом (смахните вверх тремя или четырьмя пальцами либо нажмите клавишу Mission Control). Наведите указатель на любое окно, чтобы отобразить кластер элементов управления, или используйте клавиатуру:

| Действие | Сочетание клавиш | Применяется к |
|---|---|---|
| Закрыть окно | ⌘W | окно под указателем |
| Свернуть окно | ⌘M | окно под указателем |
| Развернуть окно | ⌘F | окно под указателем |
| Скрыть программу | ⌘H | окно под указателем |
| Завершить программу | ⌘Q | окно под указателем |
| Закрыть все окна | ⌥⌘W | все окна |
| Свернуть все окна | ⌥⌘M | все окна |
| Скрыть все, кроме этого | ⌥⌘H | все программы, кроме той, что под указателем |

Каждое сочетание клавиш можно переназначить в разделе «Настройки» → «Сочетания клавиш». Включать и отключать CloseUp можно в любой момент через значок в строке меню или «Настройки» → «Основные».

## Настройки

- **Основные** — включение и отключение, запуск при входе в систему, скрытие значка в строке меню, состояние Универсального доступа с предоставлением в одно нажатие, отображаемые кнопки управления и язык программы.
- **Сочетания клавиш** — переназначение каждого действия.
- **Обновления** — автоматическая проверка (канал «Стабильный» или «Бета») и кнопка «Проверить наличие обновлений» вручную.
- **О программе** — версия, лицензия, ссылка на репозиторий GitHub и благодарности.

## Сборка из исходного кода

```bash
brew install xcodegen
make build      # Отладочная сборка (отдельная идентичность «CloseUp Dev»)
make dev-cert   # опционально: стабильная локальная подпись, чтобы разрешение
                # Универсального доступа сохранялось между пересборками
make test       # модульные тесты + проверки локализации
make run        # сборка и запуск
make dmg        # упаковка в .dmg для установки перетаскиванием
```

Проект Xcode генерируется из `project.yml` с помощью XcodeGen и не добавлен в репозиторий. См. [../DESIGN.md](../DESIGN.md) для описания архитектуры и [../RUNBOOK.md](../RUNBOOK.md) для описания процесса выпуска.
